A push-based Sokoban solver in a single Node file. It splits each level into its hallway rooms, solves every room with A* over pushes (Hungarian assignment heuristic, dead-square / corner / 2×2 / frozen-box pruning, transposition table), and walks the player between rooms along the hallway — aiming for the push-optimal count on every instance.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=practice/input MAKEFUN_OUTPUT_DIR=out node main.ts
```
